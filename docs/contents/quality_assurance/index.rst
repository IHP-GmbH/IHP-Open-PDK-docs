Quality Assurance
=================

Quality-assurance collateral is delivered under ``ihp-sg13g2/libs.qa/``.

The current QA tree is organized around DRC and LVS-related data and is intended
to support regression and library-quality checks.

The top-level QA README currently proposes this structure:

.. code-block:: text

   .
   |- drc/
   |  |- devices/
   |  |- layers/
   |  `- special/
   `- lvs/
