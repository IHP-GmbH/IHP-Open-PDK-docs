Reference Libraries
===================

Reference libraries are delivered under ``ihp-sg13g2/libs.ref/``.

These are the reusable design libraries provided to designers, including digital
standard cells, IO libraries, SRAM macros, and primitive-library content.

Reference-library naming follows the SG13G2 convention:

``<process>_<library type>_<library name>``

For the currently documented reference libraries, this gives:

- ``sg13g2_stdcell``
- ``sg13g2_io``
- ``sg13g2_sram``
